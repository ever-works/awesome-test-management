## QA Platforms

- [Testomat](https://testomat.io) - AI-powered test management tool for modern QA workflows that unifies automated and manual testing in a single platform. It connects BA, Dev, QA, and non-tech stakeholders into one loop, offering AI agents for test generation, flaky test detection, and failure clusterization across CI/CD, Jira, Slack, and GitHub integrations. ([Read more](/details/testomat.md)) `AI Powered` `API` `Cloud`
- [Aqua ALM](https://aqua-cloud.io/) - Aqua ALM is an AI-powered test management platform that unifies manual and automated testing with requirements management and defect tracking. It offers smart test case generation, flaky test detection, and integrations with Jira, Azure DevOps, GitLab, and major CI/CD tools. Cloud-based with enterprise pricing. ([Read more](/details/aqua-alm.md)) `Paid` `Enterprise` `API` `AI Powered`
- [Bencher](https://bencher.dev/) - Suite of continuous benchmarking tools designed to catch performance regressions in CI. Open-source benchmarking platform released under MIT and Apache-2.0 licenses, written in Rust. ([Read more](/details/bencher.md)) `Open Source` `Self Hosted` `Benchmarking` `CI`
- [BrowserStack Test Management](https://www.browserstack.com/test-management) - BrowserStack Test Management is a commercial cloud-based QA platform that combines test case management with test automation capabilities. It offers AI-powered test case suggestions generated from requirements documents and integrates with CI/CD pipelines for automated test result ingestion. The platform supports test case repositories, execution tracking, defect linking, and reporting for modern QA teams. Pricing is commercial/paid. ([Read more](/details/browserstack-test-management.md)) `Paid` `Commercial` `AI Powered` `Cloud` `API`
- [Keploy](https://keploy.io/) - Keploy is an API testing and test generation tool that uses AI-powered automatic test case generation from real API traffic captured via eBPF. It supports REST, GraphQL, and gRPC, generates mocks for external dependencies, and provides full test coverage metrics and analytics. Free open source core with enterprise plans available at keploy.io/pricing. ([Read more](/details/keploy.md)) `Open Source` `AI Powered` `API Testing` `Free Plan` `CI/CD`
- [Kualitee](https://kualitee.com/) - Kualitee is a test management platform that combines test case management, defect tracking, and test automation integration in a unified workspace. It offers customizable workflows, real-time dashboards, and connections to Jira, GitHub, and CI tools. Cloud-hosted with tiered subscription plans. ([Read more](/details/kualitee.md)) `Paid` `API`
- [PractiTest](https://www.practitest.com/) - PractiTest is an end-to-end test management platform that centralizes QA processes including requirements, test runs, and defect tracking. It features customizable fields, hierarchical filter trees, and integrations with Jira, GitHub, and automation tools. Cloud-based with enterprise-grade security. ([Read more](/details/practitest.md)) `Paid` `Enterprise` `API`
- [Qase](https://qase.io/) - Qase is a modern test management platform offering a free tier for small teams and paid plans for scaling. It combines test case management, defect tracking, and real-time reporting with a focus on developer-friendly workflows and API-first design. Cloud-only deployment. ([Read more](/details/qase.md)) `Freemium` `Free Plan` `API` `AI Powered`
- [Request Inbox](https://requestinbox.dev/) - Collect and inspect HTTP requests for testing and debugging. Create and manage inboxes, capture detailed request data, and configure custom responses. ([Read more](/details/request-inbox.md)) `Open Source` `Self Hosted` `HTTP` `Debugging`
- [SpiraTest](https://www.inflectra.com/SpiraTest) - SpiraTest by Inflectra is a comprehensive ALM and test management platform covering requirements, test cases, tasks, and bugs with full traceability. It offers both cloud and on-premise deployment, robust reporting, and integrations with Jira, Azure DevOps, and automation frameworks. ([Read more](/details/spiratest.md)) `Paid` `Enterprise` `API` `Self Hosted`
- [WebHook Tester](https://webhooktester.com/) - Powerful tool for testing WebHooks and more. ([Read more](/details/webhook-tester.md)) `Open Source` `Self Hosted` `Webhooks` `Testing`
- [Zephyr](https://www.smartbear.com/product/zephyr-squad) - Zephyr Squad (by SmartBear) is a test management solution tightly integrated with Jira, offering advanced planning, execution, and reporting capabilities. It supports both cloud and server deployments and scales for enterprise teams with features like test metrics and traceability. ([Read more](/details/zephyr.md)) `Paid` `Enterprise` `API` `Jira Native`

## Exploratory Testing

- [TestPad](https://testpad.com/) - TestPad is a lightweight test management tool optimized for exploratory and session-based testing with a checklist-style interface. It requires no scripting, supports keyboard-driven workflows, and integrates with Jira, GitHub, and Slack. Cloud-only with simple per-tester pricing. ([Read more](/details/testpad.md)) `Paid` `API` `Exploratory Testing`

## Jira Native Test Management

- [QMetry for Jira](https://www.qmetry.com/) - QMetry for Jira is a test management solution that operates natively inside Jira, enabling teams to create, execute, and track test cases alongside development work. It offers manual test management, cross-project reporting, BDD support, data residency options, and no-code test automation. The product is a paid offering with a free trial available. ([Read more](/details/qmetry-for-jira.md)) `Jira Native` `Paid` `Enterprise`
- [Xray](https://www.getxray.app/) - Xray is a Jira-native test management app that turns Jira into a full QA platform supporting manual, automated, and exploratory testing. It provides traceability from requirements to defects and integrates with CI/CD pipelines. Available for Jira Cloud, Data Center, and Server. ([Read more](/details/xray.md)) `Paid` `Enterprise` `API` `Jira Native`

## Open Source Test Management

- [Kiwi TCMS](https://kiwitcms.org/) - Kiwi TCMS is an open-source test case management system with a web interface, supporting test plans, cases, runs, and bug tracking integration. It is self-hosted, written in Python/Django, and offers a REST API for automation. Licensed under GPL-2.0 with active community development. ([Read more](/details/kiwi-tcms.md)) `Open Source` `Self Hosted` `Free` `API`
- [Klaros Test Management](https://www.klaros-testmanagement.de/) - Klaros Test Management is an open-source test case management platform designed for self-hosted deployment. It supports containerized installation via Docker on both Windows and Linux, enabling teams to manage test cases and test cycles without vendor lock-in. The project is freely available as open-source software. ([Read more](/details/klaros-test-management.md)) `Open Source` `Self Hosted` `Docker`
- [Nitrate](https://nitrate.io/) - Nitrate is an open-source test case management system originally developed by Red Hat, featuring test plans, cases, runs, and reporting with a Django backend. It is self-hosted, supports Bugzilla and Jira integration, and provides a REST API. Licensed under GPL-2.0 with community maintenance. ([Read more](/details/nitrate.md)) `Open Source` `Self Hosted` `Free` `API`
- [RTH (Requirements and Testing Hub)](https://rth.alrm.org/) - RTH specializes in requirements traceability and Application Lifecycle Management (ALM) integration, providing comprehensive requirements management, test case creation with direct requirements linking, impact analysis for requirement changes, and collaborative review and approval workflows. Free, fully open source. ([Read more](/details/rth-requirements-and-testing-hub.md)) `Open Source` `Requirements Traceability` `ALM Integration` `Free Plan`
- [Squash TM](https://squashtest.org/) - Squash TM is an open-source test management platform supporting manual and automated test suites, requirements traceability, and integration with Jira and CI tools. It is distributed as Docker Compose for self-hosted deployment. The project is actively maintained and freely available under an open-source license. ([Read more](/details/squash-tm.md)) `Open Source` `Self Hosted` `Docker`
- [Tesbo Test Manager](https://tesbo.com/) - Tesbo Test Manager is an open-source test case management system built for QA teams who want to self-host, manage test cases, organize test cycles, and bring AI into their QA workflow without vendor lock-in. The platform is developed in TypeScript and actively maintained. It is freely available as open-source software. ([Read more](/details/tesbo-test-manager.md)) `Open Source` `Self Hosted` `TypeScript`
- [TestLink](https://testlink.org/) - TestLink is a classic open-source test management system providing test specification, execution, and reporting with requirement traceability. It is self-hosted, PHP-based, and supports integration with bug trackers like Bugzilla and Jira. Licensed under GPL with a long history in QA communities. ([Read more](/details/testlink.md)) `Open Source` `Self Hosted` `Free`
- [Testopia](https://testopia.org/) - Testopia is a Bugzilla-integrated test case management system with a database-driven architecture. It provides unified defect and test tracking in one location, with user permissions mimicking Bugzilla, API access for custom integrations, and bulk operations for managing test cases. Free, fully open source. ([Read more](/details/testopia.md)) `Open Source` `Bugzilla` `Free Plan` `API`

## Test Case Management

- [TestCollab](https://testcollab.com/) - TestCollab is a cloud-based test management tool emphasizing collaboration with features like real-time editing, test planning, and requirement traceability. It integrates with Jira, GitHub, GitLab, and issue trackers, and provides REST API for custom workflows. Priced per user with a free trial. ([Read more](/details/testcollab.md)) `Paid` `API`
- [Testiny](https://testiny.io/) - Testiny is a modern, lightweight test management platform with a free plan for up to 5 users. It supports test cases, runs, milestones, and dashboards with a clean UI and integrations for Jira, GitHub, and Slack. Cloud-hosted with freemium pricing. ([Read more](/details/testiny.md)) `Freemium` `Free Plan` `API`
- [TestLodge](https://testlodge.com/) - TestLodge provides a simple, no-frills test case management tool focused on ease of use for small to mid-sized teams. It offers requirements linking, test plans, and reports with integrations for Jira, GitHub, and Slack. Cloud-only with straightforward per-user pricing. ([Read more](/details/testlodge.md)) `Paid` `API`
- [Testmo](https://testmo.com/) - Testmo is a unified test management tool for modern QA teams, combining test cases, exploratory testing, and automation results in one interface. It offers self-hosted and cloud options with a focus on performance, rich markdown editing, and deep CI/CD integrations. ([Read more](/details/testmo.md)) `Paid` `Self Hosted` `API`
- [TestMonitor](https://testmonitor.com/) - TestMonitor is a cloud-based test management solution designed for structured test case organization, execution, and result analysis. It features requirements linking, risk-based testing, and integrations with Jira, Azure DevOps, and Slack. Priced per user with a free trial for evaluation. ([Read more](/details/testmonitor.md)) `Paid` `API`
- [TestRail](https://www.testrail.com/) - TestRail is a web-based test case management tool designed for QA teams to organize, track, and report on testing efforts. It supports both cloud and self-hosted deployment with extensive integrations including Jira, GitHub, and automation frameworks. Pricing is per-user with enterprise options. ([Read more](/details/testrail.md)) `Paid` `Enterprise` `API` `Self Hosted`

## Test Reporting

- [Allure TestOps](https://qameta.io/allure-testops) - Allure TestOps is a test reporting and analytics platform that aggregates results from multiple test frameworks into actionable dashboards. It supports self-hosted and cloud deployment, offers flaky test detection, and integrates with CI/CD, Jira, and test automation tools. ([Read more](/details/allure-testops.md)) `Paid` `Enterprise` `API` `Self Hosted`
- [ReportPortal](https://reportportal.io/) - ReportPortal is an open-source test reporting and analytics platform that centralizes test results from multiple frameworks into interactive dashboards. It provides real-time reporting, flaky test detection, and root cause analysis. Self-hosted with a Kubernetes operator and licensed under Apache-2.0.
